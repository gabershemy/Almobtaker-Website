# Workspace Rules

## Automatic Git Push on Task Completion
- **CRITICAL MANDATORY RULE**: Whenever you complete any feature, modification, fix, or code enhancement requested by the user, you MUST ALWAYS automatically commit the changes with a clear descriptive message and push them to GitHub (`git add .`, `git commit -m "..."`, `git push origin <branch>`) before finishing your response. Never wait for the user to request a push.
